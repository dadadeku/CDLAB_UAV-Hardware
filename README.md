# CDLAB UAV Open Platform

> 从零搭建一套可复现、可扩展的开源无人机软硬件平台。

本项目由香港中文大学（深圳）控制与决策实验室（Control and Decision Lab，CDLAB）低空小组发起，旨在促进自主无人机控制与决策领域的交流与进步。项目将开放代码与硬件设计，面向无人机学习、科研与二次开发，完整记录从硬件设计、配件选型与装配调试，到 ROS 2 感知、规划和控制算法部署的全过程。

项目目前处于早期建设阶段。我们会优先保证文档可复现、接口清晰，并持续补充设计文件、物料清单、示例代码和实飞记录。

## 项目目标

- 公开无人机机架、安装件及扩展件的设计图纸与加工说明。
- 提供包含替代型号、选型理由和预算参考的硬件清单（BOM）。
- 记录装配、接线、固件配置、标定和安全检查流程。
- 打通飞控、机载计算机与 ROS 2 之间的通信链路。
- 提供可运行的感知、规划与控制示例，并说明仿真和实机部署方法。
- 建立便于科研复现和社区协作的模块化平台。

## 系统架构

```mermaid
flowchart LR
    S[相机 / 激光雷达 / IMU] --> P[ROS 2 感知]
    P --> M[定位与建图]
    M --> N[任务与路径规划]
    N --> C[轨迹跟踪与控制]
    C --> B[飞控通信桥接]
    B --> F[飞行控制器]
    F --> A[电机与执行机构]
    F --> T[遥测与状态反馈]
    T --> P
```

系统拟采用“飞控负责底层姿态稳定与安全保护、机载计算机负责 ROS 2 算法”的分层架构。具体硬件型号、通信协议和软件版本将在完成验证后写入对应文档。

## 首版样机硬件选型

以下配置作为首版样机的当前基线。部分配件已经采购，但完整动力系统尚需经过兼容性检查、推力台测试和实机验证；最终选型以仓库后续发布的版本化 BOM 为准。

| 模块 | 当前型号或配置 | 状态与说明 |
| --- | --- | --- |
| 飞行控制器 | CUAV V6X V2 | 已确定为首版样机飞控 |
| 机载计算机 | 进迭时空 K3 COM260 国产开发板 | 用于运行 ROS 2 感知、规划与控制算法 |
| 操作系统 | Bianbu 4.0.1 | 机载计算机系统环境；软件依赖和部署方法待验证后发布 |
| 激光雷达 | Mid-360S | 用于环境感知、定位与避障；驱动、标定和安装方案待发布 |
| 无刷电机 | T-MOTOR F90，KV1300，4 个 | 已采购；电池、桨叶和整机重量匹配关系待测试 |
| 四合一电调 | T-MOTOR F60A，60 A，20 × 20 mm，支持 6–8S | 已采购；安装孔位、供电和散热方案待验证 |
| 桨叶 | GEMFAN 51466 V2 MCK，5 英寸三叶桨，每包含 2 个正桨和 2 个反桨，共 2 包 | 已采购；与 F90 电机及目标工况的兼容性待验证 |

> 注意：上表记录的是当前研发选型，不构成可直接照搬的成熟动力方案。尤其是电机、桨叶、电调和电池必须作为一个整体完成电压、电流、温升、推力和结构安全测试后，方可进入实机试飞。

## 计划公开的内容

### 1. 硬件设计

- 机架及载荷安装结构
- 飞控、机载计算机与传感器安装件
- 二维工程图、三维模型和加工文件
- 装配步骤、紧固件规格与注意事项
- 重量、重心和结构版本记录

### 2. 配件选型

- 飞行控制器与配套模块
- 机载计算机
- 电机、电调、桨叶和动力电池
- 相机、激光雷达、IMU、GNSS 等传感器
- 遥控、数传、供电与安全配件
- BOM、选型依据、兼容性说明和可替代型号

物料清单将区分“候选”“已采购”“台架验证通过”和“实飞验证通过”等状态，避免将采购记录直接等同于经过验证的推荐方案。公开资料不会包含订单号、联系方式、收货地址或其他个人与采购隐私信息。

### 3. ROS 2 软件栈

- 开发环境与依赖安装
- 飞控通信与话题/坐标系约定
- 传感器驱动和时间同步
- 状态估计、定位与建图
- 障碍物感知与环境表示
- 全局/局部路径规划与轨迹生成
- 轨迹跟踪、控制指令下发和安全保护
- 仿真、室内测试和实机飞行教程

## 规划中的仓库结构

```text
CDLAB_UAV-Hardware/
├── README.md                 # 项目入口
├── LICENSE                   # 开源许可证
├── hardware/
│   ├── cad/                  # 三维模型与源设计文件
│   ├── drawings/             # 工程图与加工文件
│   ├── electronics/          # 接线图与电气说明
│   └── assembly/             # 装配文档
├── bom/                      # 物料清单与选型记录

│   ├── calibration/          # 标定与检查
│   ├── ros2/                 # ROS 2 环境和接口
│   └── flight-tests/         # 测试流程与飞行记录
```

## 快速开始

项目仍在搭建中。首个硬件版本和软件环境经过验证后，将在 [`docs/getting-started`](docs/getting-started) 中提供完整教程，包括：

1. 按照 BOM 准备零部件并完成装配。
2. 检查供电、接线、桨叶方向和急停措施。
3. 安装指定版本的系统、ROS 2 和飞控通信组件。
4. 在无桨或仿真环境中验证传感器、坐标系和控制链路。
5. 依次完成台架测试、低风险悬停测试和算法飞行测试。

在文档和首个稳定版本发布前，请勿将本仓库内容直接用于无人值守或高风险飞行。

## 如何参与

欢迎通过 Issue 和 Pull Request 参与项目。你可以帮助我们：

- 复现装配或软件流程并反馈缺失步骤；
- 补充不同地区可购买的替代配件；
- 改进 CAD、接线图、文档和 ROS 2 功能包；
- 提交仿真场景、测试数据、算法接口或实飞结果；
- 报告安全问题、兼容性问题和文档错误。

提交改动时，请说明测试环境、软硬件版本、复现步骤和验证结果。涉及飞行安全的问题，请避免公开敏感利用细节，并优先联系项目维护者。

## 安全声明

无人机的装配、调试和飞行具有潜在危险。使用本项目时，请遵守所在地法律法规和空域要求，并采取可靠的失控保护、急停、限高、地理围栏和人员隔离措施。首次测试应在仿真或拆除桨叶的条件下进行，实飞必须由具备相应能力的人员在安全场地完成。

本项目提供的设计和代码主要用于学习与科研。使用者应自行评估适航性、可靠性以及由使用或改装引起的风险。
